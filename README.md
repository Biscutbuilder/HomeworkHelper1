# HomeworkHelper1

## ABOUT
This project is a Canvas reminder, it works by using a Canvas LMS API key to see your missing assignments and what classes you're in. If you are missing a assignment the project will remind you to do it via desktop notification, and if you are all up to date in all of your classes, then the project will send a desktop notification to tell you that you are caught up. The project does this once every 3 hours, giving you a reminder for each class you are in, then waiting 3 hours before doing it again.
